# طقطقة

**افتح الموقع: [taqtaqa.ghofran-salem.workers.dev](https://taqtaqa.ghofran-salem.workers.dev)**

موقع تدريب على الكتابة بالعربي، شبه Monkeytype، بس النصوص فيه أمثال مصرية وكلام مصري وحواديت جحا وحكم وشعر عربي.

## المميزات

- أوضاع: وقت، عدد كلمات، اقتباس كامل بطول تختاره.
- كيبورد على الشاشة بترتيب ويندوز (Arabic PC) أو ماك، بيوريك الزرار الجاي واللون بيقولك أنهي صباع.
- تساهل في الهمزات والتاء المربوطة والألف المقصورة (ممكن تقفله).
- التشكيل: قسم فيه جمل كلماتها معناها بيتغير بالحركات، واختيار «التشكيل» بيخلي الحركات تظهر ولازم تكتبها.
- وضع تركيز: الإطار بيختفي وانت بتكتب.
- ١٣٥ ثيم.
- نتيجة فيها السرعة والدقة ورسمة للسرعة على مدار الاختبار، وأحسن رقم ليك محفوظ على جهازك.

## تثبيته كتطبيق

- **سفاري على الماك:** File ← Add to Dock.
- **كروم أو Edge:** أيقونة التثبيت في آخر شريط العنوان، أو القايمة ← Cast, save and share ← Install page as app.
- **آيفون أو آيباد:** زرار المشاركة ← Add to Home Screen.

بعد أول فتحة، الموقع بيشتغل من غير نت كمان.

## الاختصارات

| الزرار | الوظيفة |
| --- | --- |
| `Tab` | النص اللي بعده |
| `Shift` + `Tab` | النص اللي قبله |
| `Esc` | إعادة نفس النص |
| `Ctrl` + `Shift` + `P` | الثيمات |

## الخط

الموقع مكتوب بخط **ثمانية** ([font.thmanyah.com](https://font.thmanyah.com))، وحقوق الخط لثمانية.

- الثيمات، وترتيب كيبورد ماك، وقائمة الكلمات المصرية، وجزء من الاقتباسات مأخوذين من [Monkeytype](https://github.com/monkeytypegame/monkeytype)، ورخصته GPL-3.0. وعشان كده المشروع ده برضه برخصة **GPL-3.0** (شوف ملف `LICENSE`).
- الأمثال الشعبية والشعر والنصوص التراثية من الملك العام. الكلام المصري والحواديت مكتوبين للمشروع.
